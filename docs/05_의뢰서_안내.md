# 의뢰서 남기기 안내

## 의뢰서란
원하는 집의 조건을 글로 남기는 기능이에요. 위쪽 메뉴의 "의뢰서 남기기"나 매물 상세 화면의 "의뢰하기" 버튼으로 들어가요. 실명과 연락처는 받지 않아요.

## 써야 하는 칸 (5개 모두 필수)
- 닉네임: 1~20자
- 희망 지역: 1~20자 (예: 마포구)
- 예산: 만원 단위, 숫자만. 1만원부터 1,000,000만원(100억)까지 (예: 20000 은 2억원)
- 방 수: 1개, 2개, 3개, 4개, 5개 중에서 하나 고르기
- 요청 내용: 1~200자 (예: 햇빛이 잘 들고, 역에서 10분 안쪽이면 좋겠어요.)

쓰는 동안 오른쪽 "내 의뢰서"에 내가 쓴 내용이 바로 채워져요. 예산은 "2억원까지"처럼 읽는 말로도 보여 줘요.

## 받지 않는 정보
집결은 실명, 전화번호, 이메일을 받는 칸이 없어요. 닉네임이나 요청 내용에 전화번호 모양(예: 010-1234-5678)이 들어 있으면 저장하지 않고 이렇게 안내해요.
- 닉네임: "전화번호는 받지 않아요. 닉네임만 써 주세요."
- 요청 내용: "전화번호는 받지 않아요. 지우고 다시 남겨 주세요."

## 잘못 썼을 때
한 칸이라도 규칙에 맞지 않으면 의뢰서가 저장되지 않아요. 맨 위에 "N곳을 다시 확인해 주세요. 쓴 내용은 그대로 있어요."라고 나오고, 틀린 칸 아래에 이유가 나와요. 이미 쓴 내용은 지워지지 않으니 틀린 칸만 고쳐서 다시 보내면 돼요.
- 닉네임이 비었거나 20자를 넘으면: "닉네임은 1~20자로 써 주세요."
- 예산에 글자를 쓰면(예: 이억): "예산은 숫자만 써 주세요. (예: 20000)"
- 예산이 0이거나 너무 크면: "예산은 1만원부터 1,000,000만원(100억)까지 쓸 수 있어요."
- 방 수를 고르지 않으면: "방 수는 1~5 중에서 골라 주세요."
- 요청 내용이 비었거나 200자를 넘으면: "요청 내용은 1~200자로 써 주세요."

## 보낸 뒤에는
"의뢰서 보내기"를 누르고 저장에 성공하면 "의뢰서가 접수됐어요"라는 안내가 한 번 나와요. 화면 아래 "최근 의뢰서"에 가장 최근 의뢰서 6개가 보이고, 내 글도 거기에 나와요. 새로고침해도 같은 의뢰서가 두 번 저장되지 않아요.

## 주의할 점
- 최근 의뢰서는 누구나 볼 수 있어요. 그래서 개인정보는 쓰지 말아 주세요.
- 보낸 의뢰서를 고치거나 지우는 기능은 아직 없어요.
- 의뢰서를 남겨도 따로 연락을 드리지 않아요 (연락처를 받지 않기 때문이에요).
